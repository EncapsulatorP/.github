## How to read the work

Repositories are experiments, not automatically mathematical claims.

Results should distinguish between:

**Theorem** · proven
**Empirical** · computationally supported
**Conjectural** · hypothesis under test
**Speculative** · exploratory or incomplete
**Tooling** · research infrastructure
